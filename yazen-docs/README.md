# Yazen — Sistema de Gestão Escolar

Sistema de gestão da rede municipal de ensino. Cliente inicial: SEMED Xinguara (PA).

| Pasta | Conteúdo |
|---|---|
| `docs/` | Especificação funcional e diagramas (perfis, ERD, grade horária) |
| `design/stitch/` | Protótipos visuais exportados do Stitch |
| `backend/` | Aplicação Laravel (web + API) |
| `mobile/` | App Flutter (fase 2) |
| `solver/` | Serviço de geração de horário — Python + OR-Tools (fase 2) |

**Stack:** Laravel 12 · PostgreSQL · Redis · Filament · Livewire · Tailwind · Flutter · OR-Tools · Docker (Easypanel)

Diagramas: abra `docs/diagramas/visualizar.html` no navegador.
